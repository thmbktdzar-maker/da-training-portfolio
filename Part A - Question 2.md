•	Question 2 - Role comparison

Explain what a Data Analyst does, and how the role differs from a Business Analyst, a Data Scientist and a Data Engineer.



**Data Engineer**

Data Collection \& Storage

(Examples plain old CSVs, SQL databases, AWS buckets in the cloud)	

(Skills required: Programming, Scripting and Database Knowledge)	

	Built and optimize systems for data analysts for data scientists

	Construct pipelines so that data is properly received and stored



**Data Analyst**

Data Cleaning and Transformation	

(Skills required: Advanced Excel, SQL skills)

	Cleaning transforming and analyzing data

	Performing exploratory data analysis

	Creating reports and dashboards



**Data Analyst**

Data Exploration Analysis	

Skills required: BITools (Tableau or PowerBI) and Python	

	Pull, analyze and interpret data 

	Extract meaningful actionable insights that solves business critical problems



**Data Scientist**

Predictive Analysis

In addition (Master’s degree in Math and Stats)	

	Experimenting

	Developing machine learning etc.



**Business Analyst**	

	Documenting problems

	Writing specs

	Gathering requirements

	Mapping processes





How do we know what happened? Data Engineers 

What happened? Data Analysts 

What will happen? Data Scientists
